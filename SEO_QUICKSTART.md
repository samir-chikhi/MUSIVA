# 🚀 SEO Quick Start – MUSIVA.fr

**Vous êtes ici :** Optimisations techniques complétées ✅  
**Prochaine étape :** Google Search Console + indexation 🎯

---

## 🔥 Top 3 actions à faire MAINTENANT (20 minutes)

### 1️⃣ Google Search Console (10 min)
```
1. Aller sur https://search.google.com/search-console
2. Cliquer "Ajouter une propriété"
3. Coller : musiva.fr
4. Vérifier via DNS (TXT chez OVH) ou fichier HTML
5. Une fois vérifié → Sitemaps → Ajouter sitemap → taper "sitemap.xml"
6. Cliquer "Demander l'indexation" sur accueil
```

**Résultat attendu :** Google commence à indexer en 24-48h ⏱️

### 2️⃣ Google My Business (8 min)
```
1. Aller sur https://www.google.com/business/
2. Créer ou revendiquer "Le Génie"
3. Adresse : 12 rue du Génie, 82000 Montauban
4. Catégories : Tiers-lieu / Coworking
5. Ajouter photo + horaires
6. Valider email
```

**Résultat attendu :** Apparaître en local search + Google Maps 📍

### 3️⃣ Vérifier que tout fonctionne (2 min)
```
1. Ouvrir https://musiva.fr/robots.txt → doit afficher du texte
2. Ouvrir https://musiva.fr/sitemap.xml → doit afficher XML avec 25 URLs
3. Attendre 24h = premiers impressions dans GSC 📊
```

## 📞 Besoin d'aide ?

**GSC ne montre rien ?**
- Attendre 24-48h (normal)
- Vérifier que robots.txt n'a pas "Disallow: /"
- Vérifier sitemap.xml accesible

**Impressions mais pas de clics ?**
- Meta descriptions trop génériques (revoir)
- Title pas assez cliquable (ajouter mots-clés)

**Clics mais peu de pages vues ?**
- Utilisateurs quittent rapidement (UX/contenu faible)
- Ajouter contenu de qualité (blog articles, FAQ)
